🏥 LifeLink – Healthcare Management Platform

LifeLink is a full-stack healthcare management web application designed to simplify and digitalize healthcare services. The platform enables users to access healthcare-related features efficiently while providing administrators with tools to manage data and operations smoothly.

This project was developed as part of an IT/Engineering academic project with a focus on real-world application, clean architecture, and scalability.

🚀 Features
👤 User Side

User-friendly healthcare web interface

Secure authentication and access

Smooth navigation and responsive UI

Centralized healthcare-related information

🛠️ Admin Panel

Admin dashboard for managing system data

Control over users and platform content

Separate admin interface for better security

⚙️ Backend

RESTful APIs for frontend–backend communication

Secure server-side logic

Structured data handling

⚙️ Installation & Setup

Follow these steps to run the project locally:

1️⃣ Clone the Repository
git clone https://github.com/NeoSoham/ITproject.git
cd ITproject

2️⃣ Install Dependencies

Install dependencies separately for each module:

cd frontend
npm install

cd ../admin
npm install

cd ../backend
npm install

3️⃣ Run the Project

Start Backend

cd backend
npm start


Start Frontend

cd frontend
npm start


Start Admin Panel

cd admin
npm start
