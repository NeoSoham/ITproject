# LifeLink – Healthcare Management Platform

LifeLink is a full-stack healthcare management web application designed to digitalize and simplify healthcare services.  
The platform provides an easy-to-use interface for users and a dedicated admin panel for management.

This project was developed as part of an academic IT/Engineering curriculum with a focus on real-world applicability.

---

## 🚀 Features

### User Module
- Secure authentication system
- Clean and responsive UI
- Easy navigation across healthcare services
- Centralized access to healthcare-related information

### Admin Module
- Dedicated admin dashboard
- Manage users and platform data
- Role-based access control

### Backend
- RESTful APIs
- Secure server-side logic
- Structured data handling

## ⚙️ Installation & Setup

### Step 1: Clone the repository
```
git clone https://github.com/NeoSoham/ITproject.git
cd ITproject
```

### Step 2: Install dependencies
```
cd frontend
npm install

cd ../admin
npm install

cd ../backend
npm install
```

### Step 3: Run the project

Start backend:
```
cd backend
npm start
```

Start frontend:
```
cd frontend
npm start
```

Start admin panel:
```
cd admin
npm start
```
